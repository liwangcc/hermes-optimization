# 记忆功能的上游投稿计划

**现在只做本地准备。** 审阅从 [三份征询草稿](ISSUES.md) 开始。逐份得到发布授权后发出，先问维护者愿意看哪一段；明确回应后，再准备并请用户批准对应的独立 PR。不把「愿意审」理解成「同意合并」。[执行手册](RUNBOOK-HERMES.md) · [PR 正文](PR-DRAFT.md) · [证据](validation/EVIDENCE.md) · [Mac 复验](MAC-TEST.md)

## 1. 希望解决什么

- **内置记忆离写入上限还有多远**：界面现在显示的是文件字节数，回答不了这个问题。先只做 `USER.md`、`MEMORY.md` 的「已用字符 / 上限」。provider 自报用量、只读体检、提醒、目录提示都是后续，不绑在首个 PR。
- **已有事实的向量索引**：上游的对话后补索引本来就能补齐，缺的是由用户显式启动、看到进度和结果的入口。任务内容、分批与续跑由 provider 决定，核心不认识某个插件或模型。
- **Holographic 的桌面设置**：让目录里的 Holographic 在已有面板里配置 embeddings，不需要主库新接口。

## 3. 三个仓库的关系

| 仓库 | 放什么 | 能否独立合并和发布 |
|---|---|---|
| `NousResearch/hermes-agent`（核心和 Desktop） | 通用约定和界面：`MemoryProvider` 上默认无效的可选方法、`GET /api/memory` 的 `layers`、任务的 CLI 和 Desktop 入口 | PR3、PR7 各自独立。已有 provider 不需要改任何东西 |
| `itpartypattaya/hermes-plugin-holographic`（目录分发的插件） | 它自己的设置声明，以及将来用它自己的 embedding 路径实现的钩子 | HOLO-1 现在就能合并发布，用的是主库已有的面板。HOLO-2、HOLO-3 要等带有对应接口的核心版本 |
| `liwangcc/hermes-optimization`（本仓库） | `holographic-semantic` 参考适配器和本机侧车 | 是钩子的参考使用方，不是 Hermes 或上游 Holographic 的依赖。在没有这些接口的 Hermes 上，适配器的新方法不会被调用 |

对外引用适配器时只用**可访问的提交 SHA**，没发布就写明未发布。插件维护者没回复不算认可字段语义。

## 4. 「升级后只用旧功能，会变什么」

| 切片 | 默认配置下升级 | 用户主动使用 | 没有 provider，或 provider 没实现钩子 | 侧车不可用 | 新旧客户端与后端混用 | 回滚 |
|---|---|---|---|---|---|---|
| PR3 | **有意的可见变化**：面板多出两行用量；`GET /api/memory` 多一个 `layers` 字段，原有字段不变〔读〕。每次请求多读并解析两个内置文件；有活动 provider 时加载它并调用 `usage_report`〔读〕。不写文件、不调模型，记忆的写入和召回代码没有改动〔读〕 | 没有开关，展示即全部功能 | 没有 provider 时 provider 层为 `disabled`，内置两行照常〔测〕；没实现钩子显示「未报告」而不是 0〔测〕 | 与核心无关。参考适配器的 `usage_report` 只读 SQLite，不访问侧车〔读〕 | 新 Desktop 对旧后端显示「此版本不报告用量」，不显示 0〔测〕。旧 Desktop 和 web dashboard 对新后端：多出的字段被忽略〔读，未用旧客户端实跑〕 | 无持久状态、配置键或迁移〔读〕 |

## 5. 提交与证据纪律

| 阶段 | 门槛 |
|---|---|
| 本地候选 | 白名单提交适配器和侧车；另提交补丁、验证工具和文档。测试用独立安装、合成库，原始证据留在本机。 |
| 发征询 | 用户看过正文并同意，检查当前已有讨论；每帖一两条代表性数字及其适用范围，一个问题。跨库引用只用真实存在的编号。 |
| 发独立 PR | 维护者明确愿意审该段；按手册针对最新 base 验收，附完整结果、复现命令与限制，另获发布授权。 |
| 适配器发版 | 等对应 Hermes 接口有正式发布版本，再说明兼容范围、升级和重启侧车、回滚。候选不当作正式发版。 |

验证说明刻意分开三类：旧 Holographic 的真实模型「对话后回填」、早期 Desktop 的替身侧车 E2E、独立实装的真实 BGE-M3。**测试数量不是性能收益**，嵌入模型测试也不等于 PR4 的真实生成模型体检。macOS 结果等朋友回执，不从 Windows 外推。
