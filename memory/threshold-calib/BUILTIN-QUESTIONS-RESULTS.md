# 内置自然问句小库的阈值跨库实测

2026-11-22。验证用一套内置题库能否给每个向量模型定出可迁移的本地阈值。现有初始化任务用事实片段作探针，在真实库给 BGE-M3 建议 0.71。此前试跑 0.71 时，方案二在两个库均救回 0 题。

**本轮未通过。** 按预设条件，N 通过 1/3 个模型，Z 通过 2/3 个模型。按预设分支，后续用本库抽取的事实来生成自然问句并定值。

| 规则 | 真实库未通过的模型 | 救回 / 丢失 | 新增非答案 |
|---|---|---:|---:|
| N | BGE-small-zh v1.5 | 5 / 0 | 12 |
| N | Multilingual MiniLM-L12 v2 | 0 / 0 | 1 |
| Z | Multilingual MiniLM-L12 v2 | 1 / 0 | 3 |

## 测量方法

- 定值仅用 `issue95-evidence/synthetic` 的 `facts.json`、`blind_keywords.json`、`queries.json`、`queries_ext.json`。30 条事实经基座写入，保留盲写关键词。48 题中 36 道有答案、12 道无答案。
- 事实向量由受管侧车以 `content + " " + tags` 生成。问候和未通过 `worth_asking(query, before_turn=True)` 的题不参加定值。其余题取余弦最高的事实，用 0.05 到 0.99、步长 0.01 的网格选值。
- N 最大化正确放行数减错误放行数。错误放行包含有答案题放错首名和无答案题放行。并列时选最长连续区间的中点，同长度区间取阈值较高的一段，中点落在两格之间时取较高网格点。Z 取无答案题放行数为 0 的最低阈值。
- 六个阈值定好后才打开冻结真实库及题目。真实库有 54 条事实，54 题中 44 道有答案。受管 CUDA 侧车和 `holographic-semantic` 0.6.0 经 Holographic 0.30.0 的 `prefetch` 实测，每题使用新会话。合成库的同流程结果仅作定值集对照。
- 一条准则通过需在三个模型的真实库结果中均满足救回大于 0、基线目标丢失数为 0、新增非答案不多于救回数。噪声行是有召回的无答案题，混淆行是前 5 条含非目标的有答案题。救回、丢失和新增非答案均相对本模型的「语义关」。

权重按 `local_models.py` 的固定版本校验文件大小和 SHA-256。

| 模型 | 固定版本 | 维度 |
|---|---|---:|
| BGE-M3 | `5617a9f61b028005a4858fdac845db406aefb181` | 1024 |
| BGE-small-zh v1.5 | `7999e1d3359715c523056ef9478215996d62a620` | 512 |
| Multilingual MiniLM-L12 v2 | `e8f8c211226b894fcb81acc59f3b34ba3efd5f42` | 384 |

## 合成库定值结果

1 道无答案题被门禁跳过，参与定值的是 47 题，其中 11 道无答案。Z 的无答案误放均为 0。

| 模型 | N 阈值 | N 正确 / 错误放行 | Z 阈值 | Z 正确 / 错误放行 |
|---|---:|---:|---:|---:|
| BGE-M3 | 0.52 | 28 / 8 | 0.58 | 17 / 2 |
| BGE-small-zh v1.5 | 0.50 | 23 / 14 | 0.64 | 7 / 2 |
| Multilingual MiniLM-L12 v2 | 0.58 | 11 / 0 | 0.52 | 11 / 3 |

N 的最高分区间分别为 BGE-M3 的 0.50–0.53 和 0.55、BGE-small-zh 的 0.48–0.51、MiniLM 的 0.58。

## 复现

在项目根目录运行。参数指向日常版 Core、Holographic 基座和上一轮冻结的真实库及题目。脚本用临时档案启动侧车，输出阈值和计数。 [calib_builtin_questions.py](calib_builtin_questions.py)

```text
python -B memory/threshold-calib/calib_builtin_questions.py --core-src <CORE> --base-src <HOLOGRAPHIC> --store <FROZEN_DB> --queries <FROZEN_QUERIES> --weights-dir <MODEL_CACHE>
```
