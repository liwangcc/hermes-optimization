# 日常版对官方主线：同一批题、同一份关键词

2026-11-27。把日常版（包装插件加本地侧车，复核召回打开）和官方 Holographic 插件的主线放在同一批题上比。两边的事实都带同一份盲写关键词，向量模型都是本机 bge-m3，官方插件是同一个提交。

**结论：在官方探针的这些题上，日常版多答对约一成的题，展示的非答案少一半，噪声行和混淆行都更少；代价是丢 4 个官方原本能答上的答案，并且要多跑两个本地模型。**

## 怎么读

- **关键词占 38 题，不算日常版的优势。** 官方从 206 到 244 靠的是关键词。关键词是官方插件 0.6.0 自带的功能，官方公布的门禁行没有带。
- **日常版自己的部分是 29 题和减半的非答案。** 不开复核时多 21 题，来自侧车「追加余弦最近的一条」；复核再多 8 题，并把非答案从 1079 减到 524。
- **不开复核时日常版比官方更吵**（噪声行 192 对 155）。降噪全部来自复核。
- **「无 CUDA」一行不是更好，是读得更少。** 两行是同一条规则、同一个打分器；无 CUDA 只读块内事实和最近一条，有 CUDA 还读余弦第 2 到第 10 名。在这些题上多读的那部分多展示了 16 条全文，其中 15 条不是答案，命中没有变。这张表只数全文：没展示的候选走指针，无 CUDA 的指针只按余弦排，每轮约 1.8 行，有 CUDA 约 1.4 行（见 [platforms.md](../../docs/platforms.md#复核召回在没有-cuda-的机器上)）。通用读法给指针排序的好处在任务型消息上（见 ROUND2-RESULTS.md），这些题集里没有那类消息。
- **按官方门禁的四条看**（以「官方带关键词」为基线）：噪声不增、混淆不增、命中提升显著这三条满足，「不丢答案」这一条不满足。所以它不是给官方插件的提案，是另一种取舍。

## 做法

- **官方一侧**：`tools/provenance_probe.py`，提交 `67229de`（v0.31.4 加默认关闭的复核开关，工作树干净），`--emb on --modes off --repeats 1 --recall-check-margin off`，余量是默认的 1.0。带关键词的一臂加 `--keywords tools/issue95_keywords/<题集>.json`，全覆盖。行在 [`vs-official/rows/`](vs-official/rows/)。
- **日常版一侧**：第二轮赛马的冻结 pack 和冻结规则，见 [ROUND2-RESULTS.md](ROUND2-RESULTS.md)。基座是同一个官方插件关掉向量、带同一份关键词；侧车用 bge-m3 追加最近的一条（阈值 0.55）；复核用 Qwen3-Reranker-0.6B。「无 CUDA」一行是只读块内事实和最近一条的读法，见 [platforms.md](../../docs/platforms.md#复核召回在没有-cuda-的机器上)。
- **计数**：命中、噪声行、混淆行用的是裁判台 [`referee.py`](referee.py) 里照官方 `mcnemar_gate.py` 写的定义，两边同一套。
- multi（18 种语言）不在内：上游在 0.31.3 和 0.31.4 换了语料里的人名，和 11-23 冻结的 pack 对不上。

三项核对：

- 不带关键词的一臂是重跑的，和 [`upstream-check/repro/rows`](../threshold-calib/upstream-check/repro/rows/) 里存的官方行比，618 行展示的事实完全相同。
- 日常版的数据是在插件 `76689f9` 的基座块上量的。用今天的 `67229de` 重跑同一臂（`--emb off --keywords`），618 行的基座块完全相同（上游改过名的一个事实键按新名对齐）。所以两边比的是同一个版本的官方代码。
- 日常版的离线规则和真实插件端到端跑出来的结果，在 618 行里有 604 行展示的事实相同（见 ROUND2-RESULTS.md 的「插件实测」）。

## 复现

官方一侧只需要上游插件的检出、它自带的关键词文件和本机的 bge-m3：

```bash
# 仓库根目录。脚本自己起停本机的 bge-m3 向量接口
python -X utf8 -B memory/recall-race/vs-official/official_kw_run.py . <输出目录>
python -X utf8 -B memory/recall-race/vs-official/base_check.py . <输出目录>
```

对比表：

```bash
cd memory/recall-race
python -X utf8 -B vs-official/vs_official_kw.py vs-official/rows          # 618 行
python -X utf8 -B vs-official/vs_official_kw.py vs-official/rows test     # 留出池
```

日常版一侧读第二轮存下的打分（`round2/`），那个目录不在公开仓库里；官方一侧的数只用这里的行和 `pack/labels.json` 就能重算。

## 局限

- **题是合成的直接提问**，库只有几十到一百多条事实。真实个人库、多轮对话、模型实际答得好不好，都没有测。
- **官方是 v0.31.4**，不是之后的版本。
- **只有一个向量模型**（bge-m3）和一个复核模型。
- **日常版的规则常量是在这些题集的 dev 池上定的**；留出池的数更干净，但指针规则和无 CUDA 的读法是看过留出池之后定的。
- **「追加最近一条」用的向量带了关键词**，而官方的向量只用正文。这一步多出来的 21 题里，准入规则不同和关键词进向量各占多少，没有拆开测。官方自己测过关键词进向量（#95），在它的准入规则下没有可测的收益，这里的结果不改变那个结论。
- **代价**：本机常驻一个侧车和两个模型（bge-m3 加 0.6B 的复核模型），每条消息多 0.2 秒左右（有 CUDA），耗时见 platforms.md。
